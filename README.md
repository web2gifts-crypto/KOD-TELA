# Код Тела — Telegram Mini App

MVP для ВКР, который дальше живёт как продовый продукт: помощь женщинам по симптомам, анализам и циклу.

## Стек

| Слой | Выбор | Почему |
|---|---|---|
| Фронт (mini app) | React 19 + TypeScript + Vite 7 + Tailwind 4 | быстрый старт, типы, лёгкий бандл для мобильного WebView |
| Роутинг / состояние | React Router 7 (hash) · Zustand | hash-роутинг не требует настройки сервера под SPA |
| Telegram | `telegram-web-app.js` + своя обёртка `src/lib/telegram.ts` | без лишних зависимостей; вне Telegram работает на заглушках |
| Бэкенд (этап 2) | Python 3.12 + FastAPI + SQLAlchemy + Alembic | ИИ/OCR/анализ данных — экосистема Python |
| БД | PostgreSQL в РФ (Yandex Managed PG / Timeweb) | 152-ФЗ: данные о здоровье — спецкатегория, хранить в РФ |
| Бот / пуши | aiogram 3 в том же бэкенде | уведомления через Bot API |
| ИИ (этап 3) | YandexGPT (или GigaChat) + RAG по базе знаний врачей | без трансграничной передачи медданных |
| OCR (этап 3) | Yandex Vision OCR | лучше всего читает русские бланки |

## Запуск

```bash
cd web
npm install
npm run dev        # http://localhost:5173
npm run build      # проверка типов + сборка в web/dist
```

В браузере приложение работает как демо-пользователь «Катя». Данные лежат в `localStorage` (ключ `kodtela`); сброс — «Удалить мои данные» в профиле.

## Деплой (Vercel)

1. Импортировать репозиторий в Vercel — настройки берутся из `vercel.json` в корне (сборка `web/`, выдача `web/dist`). Root Directory оставить пустым.
2. Переменные окружения пока не нужны. Когда появится бэкенд — `VITE_API_URL` (см. `web/.env.example`).
3. Роутинг на hash (`/#/...`), поэтому SPA-rewrites не нужны.

## Подключение к Telegram

Mini App должен открываться по HTTPS — подходит домен Vercel.

1. В @BotFather: `/mybots` → бот → **Bot Settings → Menu Button** → указать URL деплоя и название кнопки (например, «Код Тела»).
   Либо `/newapp` — чтобы приложение открывалось по ссылке `t.me/<бот>/<app>`.
2. Открыть бота в Telegram → кнопка меню → приложение запустится внутри Telegram.

**Токен бота в код и репозиторий не кладём.** Он понадобится только бэкенду (проверка `initData`, отправка файлов и уведомлений) — хранить в переменных окружения сервера (`BOT_TOKEN`). Если токен где-то засветился — перевыпустить в @BotFather (`/revoke`).

Что уже адаптировано под Telegram (`web/src/lib/telegram.ts`): `ready/expand`, цвета шапки и фона, отключение закрытия свайпом вниз, safe area (вырезы и шапка Telegram), нативная кнопка «Назад», вибрация, имя и фото пользователя, `initData` для бэкенда. Вне Telegram приложение работает как демо (пользователь «Катя»).

## Что готово (фронтенд MVP)

Навигация: **Главная · Календарь · Анализы · Код тела**, профиль — по аватарке на главной, Юви — плавающий на всех экранах кроме главной (там он в карточке).

- **Онбординг:** слайд «Код Тела» → знакомство с Юви → что он умеет → согласие 152-ФЗ → анкета.
- **Главная:** «Юви рядом» (реплики печатаются сами, реакция на настроение, предсказание дня), карточка цикла с неделей, кнопки «Настроение» и «Чат с Юви», мои показатели, совет дня.
- **Чат с Юви:** симптом → 4 уточняющих вопроса → вердикт «норма / к врачу / скорая» + план; красные флаги → сразу скорая и пометка `flagged`.
- **Анализы:** ввод показателей (фото прикрепляется, OCR — этап 3), расшифровка, история, динамика.
- **Календарь:** сводка дня (день цикла, фаза, «месячные через N дн. ±разброс», овуляция), месяц с лентами фаз и пунктиром «возможное начало», режим «Отметить месячные» (тап по дням), шторка дня (интенсивность месячных, настроение, симптомы, заметка), прогноз по средней длине *твоих* циклов (`buildCycleModel` в `lib/cycle.ts`), свайп между месяцами.
- **Настроение:** 5 состояний Юви, фон-«погода» под настроение, факторы, заметка, график за 2 недели.
- **Мой код тела:** сводка за всё время — цикл (средняя длина, регулярность, график), настроение (распределение, серия, факторы, 30 дней), симптомы (и в какой фазе чаще), анализы (динамика), выгрузка отчёта.
- **Профиль:** разделы, демо-данные за 3 месяца (только вне Telegram — для показа), удаление данных.

### Выгрузка «Мой код тела»

`lib/report.ts` собирает HTML-отчёт (открывается везде, печатается в PDF). `lib/api.ts`:

- задан `VITE_API_URL` и приложение открыто в Telegram → `POST {API}/export` с заголовком `Authorization: tma <initData>` и телом `{ filename, content }`; бэкенд проверяет подпись и отправляет файл пользователю через Bot API `sendDocument`;
- в Telegram без бэкенда — отчёт открывается внутри приложения (WebView не умеет сохранять сгенерированные файлы);
- в обычном браузере — файл скачивается на устройство.

## Юви — маскот

`web/src/ui/Yuvi.tsx` — вектор (SVG), анимация на CSS (`styles.css`, блок «Юви»): парение, «дыхание», моргание, взгляд, пузырёк-спутник, «желе» по тапу, рот при наборе ответа.

- 5 настроений: `great · good · neutral · anxious · bad` — свой цвет и мимика.
- Настроение Юви = отметка пользователя за день, иначе считается по данным (`lib/yuvi.ts`): плохие анализы → тревожный, пограничные → нейтральный.
- Всегда на экране (плавает над таб-баром), по тапу — чат. Раз в сессию говорит реплику.
- Геймификация: серия дней с отметкой настроения 🔥, знакомство с приложением при первом входе.
- Стикерпак Юви в формате TGS можно собрать из тех же форм — отдельной задачей.
