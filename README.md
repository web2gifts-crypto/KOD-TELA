# Код Тела — Telegram Mini App

MVP для ВКР, который дальше живёт как продовый продукт: помощь женщинам по симптомам, анализам и циклу.

## Стек

| Слой | Выбор | Почему |
|---|---|---|
| Фронт (mini app) | React 19 + TypeScript + Vite 7 + Tailwind 4 | быстрый старт, типы, лёгкий бандл для мобильного WebView |
| Роутинг / состояние | React Router 7 (hash) · Zustand | hash-роутинг не требует настройки сервера под SPA |
| Telegram | `telegram-web-app.js` + своя обёртка `src/lib/telegram.ts` | без лишних зависимостей; вне Telegram работает на заглушках |
| Бэкенд (этап 2) | Python 3.12 + FastAPI + SQLAlchemy + Alembic | ИИ/OCR/анализ данных — экосистема Python |
| БД | PostgreSQL в РФ (Yandex Managed PG / Timeweb) | 152-ФЗ: данные о здоровье — спецкатегория, хранить в РФ |
| Бот / пуши | aiogram 3 в том же бэкенде | уведомления через Bot API |
| ИИ (этап 3) | YandexGPT (или GigaChat) + RAG по базе знаний врачей | без трансграничной передачи медданных |
| OCR (этап 3) | Yandex Vision OCR | лучше всего читает русские бланки |

## Запуск

```bash
cd web
npm install
npm run dev        # http://localhost:5173
npm run build      # проверка типов + сборка в web/dist
```

В браузере приложение работает как демо-пользователь «Катя». Данные лежат в `localStorage` (ключ `kodtela`); сброс — «Удалить мои данные» в профиле.

## Что готово (по макетам Figma Make, 12 экранов)

- Онбординг: приветствие → о продукте → согласие 152-ФЗ → анкета (возраст, цель, начало месячных, аватар)
- Главная: фаза, день цикла, прогноз месячных, аватар, быстрые действия, последний анализ
- Чат: симптом → 4 уточняющих вопроса → вердикт «норма / к врачу / скорая» + план, красные флаги → сразу скорая, пометка `flagged` для админки
- Анализы: ввод показателей (фото прикрепляется, OCR — на этапе 3), расшифровка с нормами, история, динамика
- Дневник цикла: календарь фаз с прогнозом, настроение, симптомы, длина цикла
- Рекомендации по фазе и анализам, избранное
- Профиль, история диалогов, уведомления

## Структура

